# 🚀 Xray-Reality 一键脚本（由Ai生成）

支持系统： Alpine / Debian / Ubuntu

支持架构： x86_64 / ARM64

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/a88wyzz/Alpine-Debian-Ubuntu-Hy2/main/Reality/reality.sh)

```

# ✨ 功能

* 安装 Xray-Reality
* 自动设置开机启动
* 输出 IPv4 / IPv6 节点链接
* 支持 systemd / openrc 进程监视守护

# ⚠️ 注意

* Xray-Reality使用TCP端口
* 默认安装端口随机，完成后可自行更改
